# Messenger

Клиентский прототип мессенджера на TypeScript без React и других UI-фреймворков. Проект демонстрирует собственную компонентную модель, событийный жизненный цикл, клиентскую маршрутизацию, валидацию форм и слой HTTP-запросов.

## Основные возможности

- экраны входа и регистрации с валидацией полей;
- список чатов и выбор одного или нескольких чатов;
- создание чатов и отправка сообщений в локальное состояние;
- профиль пользователя и форма смены пароля;
- навигация с History API и поддержкой переходов назад/вперёд;
- страницы ошибок 404 и 500 в составе набора шаблонов.

## Технологический стек

- TypeScript;
- Vite;
- HTML и CSS, Tailwind CSS;
- собственные `Block`, `View` и `EventBus`;
- History API для маршрутизации;
- `XMLHttpRequest` через собственный `HTTPTransport`;
- `.hbs`-шаблоны с небольшим собственным интерполятором;
- ESLint и Stylelint.

Проект не использует React. Пакет Handlebars также не подключён: расширение `.hbs` используется для шаблонных файлов, которые обрабатываются собственным кодом.

## Архитектура

- `core/Block.ts` связывает свойства компонента, события и жизненный цикл;
- `core/EventBus.ts` предоставляет событийную модель компонентов;
- `pages/` собирает экраны из переиспользуемых компонентов;
- `components/` содержит формы, поля, сообщения и элементы списка чатов;
- `core/store.ts` и `services/ChatsService.ts` управляют локальным состоянием чатов;
- `services/HTTPTransport.ts` инкапсулирует XHR-запросы;
- `main.ts` сопоставляет URL с экранами и синхронизирует навигацию с History API;
- `utils/validation.ts` централизует правила и сообщения валидации.

## Структура проекта

```text
src/
├── components/   # переиспользуемые UI-компоненты
├── controllers/  # контроллеры экранов и чатов
├── core/         # Block, EventBus и локальное состояние
├── pages/        # экраны приложения
├── services/     # HTTPTransport и операции с чатами
├── styles/       # глобальные стили
├── templates/    # шаблоны экранов и ошибок
├── types/        # TypeScript-типы
└── utils/        # шаблонизация и валидация
```

## Локальный запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

После запуска Vite выводит локальный URL приложения в терминал.

## Проверки

```bash
npm run typecheck
npm run lint
npm run stylelint
npm run test
npm run build
```

`npm run test` последовательно запускает typecheck, ESLint и Stylelint. Unit- и end-to-end-тестов в текущей версии нет.

## Статус проекта

Учебный клиентский проект. В текущей ветке чаты и сообщения хранятся локально; backend и WebSocket не подключены. Ранее указанная Netlify deploy-preview ссылка больше недоступна, поэтому она удалена из README.

## Моя роль

Самостоятельная реализация учебного задания: компонентная архитектура, маршрутизация, формы, валидация, локальное состояние и транспортный слой.

## Планы развития

- подключить REST API для авторизации, профиля и управления чатами;
- добавить WebSocket для обмена сообщениями;
- покрыть `Block`, `EventBus`, маршрутизацию и валидацию unit-тестами;
- добавить стабильный deployment вместо временного preview.
